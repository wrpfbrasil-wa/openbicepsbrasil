# Open Biceps

A maior base pública de resultados do Power Biceps e Strict Biceps Curl.

## Sobre

O Open Biceps é um projeto independente criado para preservar, organizar e disponibilizar resultados oficiais de competições realizadas por diferentes federações e organizações ao redor do mundo.

Inspirado em iniciativas como o OpenPowerlifting, o projeto busca criar um banco de dados permanente para atletas, árbitros, promotores e pesquisadores da modalidade.

## Recursos

- Histórico de atletas
- Resultados completos
- Rankings
- Recordes
- Estatísticas
- Busca por atleta
- Busca por competição
- Dados em formato CSV
